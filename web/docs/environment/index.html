Environment variables

#Install

variabledefaulteffect
SAETTA_PREFIX~/.localthe install script puts the binary in $SAETTA_PREFIX/bin
SAETTA_VERSIONlatestthe install script installs this release, such as 0.16.0

#Models and memory

variabledefaulteffect
SAETTA_MODELS~/Modelswhere packs are downloaded and looked up by name
HF_TOKENunseta Hugging Face token for downloads, which raises Hugging Face's limits (else ~/.cache/huggingface/token)
SAETTA_IGNORE_MEMORYunset1 loads or downloads a pack this Mac's memory is too small for, and keeps the asked context

#Server and engine

variabledefaulteffect
SAETTA_CTX32768 (saetta serve), 204800 (saetta start)context in tokens, 1024 to 262144 (Inkling 2 Mini 1048576), rounded down to a multiple of 128 (Flash-Next about 35 KB per token, 27B 64 KB)
SAETTA_PORT8080the port saetta start uses
SAETTA_CONVERSATIONS4conversations the server keeps between turns
SAETTA_SPEC / SAETTA_MTP1 / 10 turns speculative decoding / the MTP head (Inkling: the DSpark drafter) off
SAETTA_DSPARKunsetInkling 2 Mini: 1 loads the downloaded DSpark drafter (or a path to its mtp.safetensors); off by default
SAETTA_KV_F32unsetf32 KV cache
SAETTA_NO_ACCELunset1 runs without the tensor-op (neural accelerator) kernels, for a Mac where they misbehave (slower prompt reading, same output)
SAETTA_EXPERT_CACHE_GBunsetexperimental: keep this many GB of experts in memory, read the rest from the SSD (Flash-Next: slower than resident, same output)
SAETTA_LORAunsetan adapter folder for saetta generate

#Saetta Code

Saetta Code reads these variables of pi's as pi does, along with its own.

variabledefaulteffect
PI_CODING_AGENT_DIR~/.pi/agentthe agent folder (settings, models, sessions, skills, MCP); saetta start code sets ~/.saetta/pi
SAETTA_SKIP_VERSION_CHECK, PI_SKIP_VERSION_CHECKunset1 skips the update check at start
PI_OFFLINEunset1 skips the update check
PI_TRUE_COLORdetected1 forces 24-bit color, 0 256 colors
PI_HYPERLINKSdetected1 or 0 turns clickable links on or off
PI_CLIPBOARD_OSC52unset1 copies through the terminal (OSC 52), as over SSH
PI_TUI_ESC_TIMEOUT10 (100 over SSH)milliseconds to tell Escape from an escape sequence
PI_CACHE_RETENTIONunsetlong asks providers that support it for 24-hour prompt caching
SAETTA_DURABLE10 keeps no journal of the run, so an interrupted run cannot be resumed (Interrupted runs)
SAETTA_DURABLE_SYNCbarrierhow a journal record reaches the disk before a tool that is never run again starts: barrier (F_BARRIERFSYNC), full (F_FULLFSYNC), none (survives a crash of the process, not a power loss)
VISUAL, EDITORnanothe editor Ctrl+G opens, when settings.json has no externalEditor
SAETTA_STATE10 turns off the conversation state on disk (~/.saetta/state): a resumed session then reads its history again
SAETTA_AHEAD10 turns off reading a running command's output into the conversation before the next request (Sessions)
SAETTA_FEED10 turns off drafting from the files Saetta Code read, edited or wrote (Sessions)
SAETTA_FORK_POINT10 stops Saetta Code with --subagents asking the engine for a checkpoint before each answer, where its subagents' prompts leave the parent's (Parallel agents)
SAETTA_GRAMMAR01 decodes tool calls under a grammar built from the request's tools (Qwen chat format), so a call always names a tool of the request, gives its required arguments and parses; the model's own token is kept whenever it is valid (HTTP API)
